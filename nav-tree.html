Omnius TV - Nested Route Navigation

Back = go up one path segment. No history.back(). App never kills on back at root.

Current (Flat Routes)

/                    ← everything in one page
/movie/[id]           ← back: /?tab=movies
/series/[id]          ← back: /?tab=tvshows
/player/[hash]        ← back: /movie/[id] maybe?
/live                 ← back: history.back()
/settings             ← back: history.back()

Problems:
- All tabs crammed in /
- Player doesn't know parent
- history.back() unpredictable
- Back can kill the app

Proposed (Nested Routes)

/                         ← home (hero + rows)
/movies                   ← back → /
/movies/[id]              ← back → /movies
/movies/[id]/play/[hash]  ← back → /movies/[id]
/series                   ← back → /
/series/[id]              ← back → /series
/series/[id]/play/[hash]  ← back → /series/[id]
/live                     ← back → /
/live/play                ← back → /live
/favorites                ← back → /
/search                   ← back → /
/settings                 ← back → /

Rule: always goto(parent path)
- Back is deterministic
- Player always knows parent
- Root page: back does nothing

Global Back Handler +layout.svelte

Algorithm (in +layout.svelte keydown handler):

1. Let page intercept first (close modal, unwind sub-state). If handled → stop.
2. Let path = $page.url.pathname
3. If path === "/" and focus is in content area → move focus to sidebar Home
4. If path === "/" and focus is in sidebar → do nothing (swallow event, don't kill app)
5. Else compute parent = path.split("/").slice(0, -1).join("/") || "/"
6. goto(parent, { replaceState: true })

Focus check: document.activeElement.closest('.sidebar') to detect if focus is in sidebar.
